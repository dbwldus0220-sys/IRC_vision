Ball 500mm 전환 및 catalog62 미세 모션 적용

요청 반영
- 600mm 초과~1500mm 접근 분기 및 800mm 라인/공 기준 전환 유지.
- 500mm 초과~600mm 이하: r미세45도, 5회, 배속 1.05 × 0.95 = 0.9975.
- 500mm 이하: 카메라 내림 및 기존 잡기 시퀀스 진입.
  미세 전진은 r미세0도 공잡기용, 5회, 배속 0.9975.
- 허들 미세 전진: r미세 0도 허들용, 일반 5회/최종 10회, 배속 0.9975.
- 골대 미세 전진: r미세 골대전용, 기존 1~4회 선택, 배속 1.0 × 0.95 = 0.95.
- 공 소실 탐색: 공잡기용 원본으로 기존 3회 파생.
- 새 네 원본 및 여섯 파생만 추가. 기존 103개 모션 객체의 데이터는 모두 유지.
- 원본 관절값/토크/프레임 시간 보존. runtime 허용오차 5도 유지.
- 원본/PC 배속 보존. runtime은 원본 배속에 0.95를 한 번 적용.
- 공/골대 보행 예약 시간은 새 원본 주기와 runtime 배속으로 갱신.

검증
- step / mission_control / irc_step_motion_executor 빌드 성공.
- 최종 집중 검사 184개 통과(경계/원본 데이터/배속/예약 시간/모션 연결/허용오차).
- 113개 runtime 모션 및 모든 별칭/모터 ID(0~22) 유효성 검사 통과.
- import_motions.py 재실행 전후 PC/runtime/alias 파일 SHA256 동일.
- 모의 실행기: 공/허들/골대 카메라 launch 테스트 3개 통과.
- C++ test_motion_json_catalog 통과.
- C++ test_startup_pose_catalog는 기존 관절각 기대값 한 항목 실패(6개 통과).
  김오뒤3의 ID13/14는 변경 전후 모두 -40.95703125 / 54.84375.
  테스트 기대값 -41.220703125 / 55.3046875와 불일치하며 이번 수정으로
  시작 자세 관절값은 바뀌지 않았다.
- 전체 Python 테스트는 변경 전 별도 복사본과 비교. 기존 실패 560건과 동일한 실패 집합이 남았으며 추가 미해결 실패는 없다.
  전체 검사 5193 통과/563 실패 후, 새 허들 테스트 입력을 수정해 집중 재검증
  184 통과/0 실패로 추가 3건을 해소했다. regression_summary.json 참조.

실물 로봇은 구동하지 않았다. 카메라 launch 테스트의 simulated backend는
동역학/접촉/균형 시뮬레이션이 아니다. 실물 적용 전에 동역학 시뮬레이션에서
미세 보행 이동량, 500mm 경계 통과 후 완료 시점, 자세 연결과 균형을 검증해야 한다.
