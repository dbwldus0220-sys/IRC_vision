# Catalog 34 후진 모션 갱신

입력: `/home/jet/Downloads/robot_motions(34).json`.

교체한 모션은 `찐후진실전-2(2회)`, `찐후진실전(1회)` 두 개다. 두 모션 모두 관절 13/19번 각도가 바뀌었고, 2회 모션에는 프레임 시간 변경도 있다. 새 원본의 관절값, 토크, 프레임 시간, 반복 횟수, 재생 속도를 그대로 반영하고 완료 허용 오차만 5.0도로 설정했다.

기존 카탈로그를 `runtime_before.json`, 입력 파일의 요청된 두 모션을 `source_requested_motions.json`에 보관했다. `manifest.json`에 입력 파일 SHA256 및 교체 전후 모션 SHA256을 기록했다.

카탈로그는 89개를 유지하며 다른 87개 모션과 별칭 연결은 변경하지 않았다. 따라서 1회 모션은 기존 `pickup_retreat_2`, `goal_camera_90_backward_1`에서 새 데이터로 실행된다. 파생된 공 분실 후진 및 다른 복합 후진/회전 모션은 변경하지 않았다.

검증: 관련 카탈로그/보존/전체 5도 허용 오차 테스트 13개, 공잡기 후 후진 원본 일치 테스트 1개 통과. 모션 검증 도구의 89개 모션/별칭/관절 ID 0..22 검사와 `git diff --check` 통과. 실제 모션은 실행하지 않았다.

모션 파일을 메모리에 읽은 실행기는 재시작해야 새 데이터가 반영된다. 후진 관절값과 타이밍이 바뀌었으므로 실기 적용 전 시뮬레이션에서 후진 균형과 연결 자세를 확인해야 한다.
