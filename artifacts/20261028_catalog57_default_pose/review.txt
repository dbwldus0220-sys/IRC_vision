2026-10-28 기본자세 모션 갱신

첨부 robot_motions(57).json 원본은 motion_imports/에 보관했다.
원본 해시와 교체 이름은 manifest.json, 작업 전 파일은 before/에 보관했다.

PC/runtime에 교체한 모션:
- 건오뒤에서 기본자세(카메라45도) -> R오뒤에서 기본자세(카메라45도)
- R오뒤에서기본자세0도 -> R오뒤에서 기본자세(0도)
각도/토크/프레임 시간/시작·종료 자세/배속은 57번 원본을 사용했다.
두 모션 모두 65ms부터 첫 프레임 60ms, 125ms부터 마지막 프레임 110ms,
반복 1회, 배속 0.95다. 배속에 0.95를 추가로 곱하지 않았다.
runtime 완료 허용 오차는 프로젝트 정책대로 5도다.

별칭 ID는 유지하고 대상 이름만 갱신했다:
pickup_forward_to_crab_0 -> 새 0도 모션
goal_forward_to_crab_right_90, goal_forward_to_default -> 새 카메라45도 모션
골대 머리 각도 override 및 준비/꽃게/슛 실행 순서는 변경하지 않았다.
다른 사용 중인 기본자세 모션은 원본과 같았다. 첨부의 별도 골대 후 우회전 변경은
이번 기본자세 교체 범위에 포함하지 않았다. 나머지 모션/알고리즘은 보존했다.

검증:
- 관련 153개 테스트 통과: 원본 일치/다른 모션 보존, 별칭, 준비→꽃게/회전/슛,
  실패 시 다음 동작 차단, runtime 완료 허용 오차 포함.
- 카탈로그 검사: 90개 모션, 모든 별칭 정상, 모든 프레임 모터 ID 0~22 정상.
- upsert 도구 검사: 4 통과, 기존 실패 1건 유지. PC 1.0배와 runtime 0.95배를
  동일하게 요구하는 기존 검사로, 이번 두 모션 교체와 무관하다.
- 설치된 카탈로그/별칭 링크가 수정 파일과 동일한지 확인했다.
- 실물 동작은 실행하지 않았다. 데이터/별칭 변경이므로 실행기 재시작 시 적용된다.
  기본자세 전환의 관절 목표와 시간이 달라졌으므로 지지 상태에서 전환을 확인한다.
