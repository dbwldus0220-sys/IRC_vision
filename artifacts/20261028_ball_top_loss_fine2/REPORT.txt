2026-10-28 공 상단 소실 탐색: 미세 전진2회

최종 동작
- 일반 접근/접근 재정렬: BALL_LOST_FINE_FORWARD_2 -> ball_top_loss_fine_forward_45_2.
- 잡기 초기 정렬: BALL_PICKUP_INITIAL_SEARCH_FORWARD -> 같은45도2회.
- 잡기 미세 정렬: BALL_PICKUP_FINE_SEARCH_FORWARD -> pickup_top_loss_fine_forward_0_2.
- 45도 건미세45도(5회), 0도 건미세0도를 복사하여 이름과 repeat_count만 변경.
  새 이름은 건미세45도(상단탐색2회), 건미세0도(상단탐색2회). 모두 repeat_count=2, speed=1.
- 기존 일반 접근/잡기/허들 미세5회와 다른 모션 객체는 모두 그대로 유지.
- runtime과PC에 각2개만 추가. runtime tolerance 전부5도 및 원본4/5번 관절각 유지.

실행 연결
- 기존 최초미검출/상단위치/추적상태/소실당1회 제한은 유지.
- 일반 탐색용 새 action은 일반 모션 gate와 미세 전진 전 안정화에 등록.
- 초기/미세 정렬 탐색도 기존 미세 전진 전 안정화와 체크포인트 잠금을 유지.
- 0도 미세 준비/정지 단계는 선택한 목표모션을 pending_pickup_fine_motion_id로 보관.
  준비 완료 뒤 하드코딩된5회 모션으로 돌아가지 않고2회 모션을 실행.
  준비 중 재탐색 전환/전체요청해제 시 해당 예약을 비움.
- 2회 완료 뒤 기존 정렬 체크포인트로 복귀하여 새 영상으로 재판단.
- 같은 소실에 자동으로2회를 계속 추가하지 않음.
- 관절각, 토크, 프레임시간, 원본의 내부정지 및 모션준비/정지 절차 유지.
- 내부화면 소실 시4회 전진, 공/허들 거리 기준은 변경하지 않음.
- 표시: BALL / FINE SEARCH 2, PICKUP / FINE SEARCH 2.

검증
- bridge/미세전진안정화/카탈로그복제/일회탐색:462개 통과.
- planner/mission flow/카탈로그허용오차/관련표시:36개 통과.
- 실제실행배너15개, 소실선택배너10개 통과.
- upsert 정책검사5개 통과. 합계528개 선택검사 통과.
- SDK 가상버스로 두 새 모션 모두 repeat 이벤트1회, goals_complete의repeat=2 확인.
- PC/runtime 기존모션 전부 변경없음 비교. 설치된alias/runtime에서도 반복2회 확인.
- 빌드 결과 build.log 참조. 실제 하드웨어 재생은 하지 않음.
- 노드 재시작 후 새 판단/alias/카탈로그가 적용됨. 실기에서 지지 상태로 짧은 재탐색 확인 필요.

이전 중간 수정
앞선 ball_top_loss_fine 폴더는 기존5회 미세모션 재사용 단계의 기록이다.
사용자의 추가 요청으로 이 폴더의2회 전용 분기로 변경했으며 최종 검증은 본 폴더 기준이다.
