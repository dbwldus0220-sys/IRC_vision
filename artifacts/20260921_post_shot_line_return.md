# 골넣기 후 라인 복귀 — 2026-09-21

## 실행 순서

- SHOT 정상 완료 수신 → 3초 대기 → 첫 번째 공은 제자리우회전45도(9회),
  두 번째 공은 제자리좌회전45도-1(4회).
- 고정 회전 완료 후 3초 대기하고 새 라인 관측으로 방향 확인. 정렬되어 있으면 보정 회전 생략.
- 오차가 크면 기존 총 회전각 표로 제자리회전 횟수 선택. 추가 보정·탐색 회전도
  매번 정상 완료 후 3초 대기하고 새 관측으로 재확인한다.
- 마지막 회전 후 3초 대기 → 새 영상에서 정렬 확인 → 전진45도-1(6회).
  이미 대기를 마친 경우 정렬 확인 뒤 3초를 중복해서 추가하지 않는다.
- 전진 성공 후 첫 번째 공은 AUTO, 마지막 공은 LINE_TRACK으로 복귀.
- 회전 또는 전진 실패·시간 초과 시 해당 단계에서 WAIT. 부분 실행된 회전을 자동 재실행하지 않음.

전용 단계는 POST_SHOT_TURN, POST_SHOT_LINE_ALIGN, POST_SHOT_FORWARD다.
골넣기 전후의 득점 판정 범위 0.77~0.82m는 변경하지 않았다.
정렬 기준은 기존 라인 정렬과 동일하며, 우측 15° 미만·좌측 30° 미만 오차에서는
최소 회전량보다 작은 보정을 생략한다. 횡방향 위치는 이 단계의 완료 조건이 아니다.
유효 관측이 없으면 대기하고, 새 영상에서 라인이 미검출되면 마지막 회전 방향으로 탐색한다.

## 모션 데이터

기존 제자리우회전45도-1(7회)를 복사해 제자리우회전45도-1(8회)를 추가했다.
이름과 repeat_count만 변경했으며 프레임·속도·완료 조건은 동일하다.
추가 시 기존 motions 배열의 모든 객체가 그대로 보존되었음을 비교했다.
후속 요청으로 첫 번째 고정 회전은 기존 제자리우회전45도(9회)로 변경했다.
현재 alias는 post_shot_turn_right_9이며 반복 횟수는 9회다. 앞서 추가한 8회 모션은
카탈로그에 보존하되 이 복귀 순서에서는 사용하지 않는다.
