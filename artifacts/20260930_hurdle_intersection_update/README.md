허들 교차점 복귀 보정 변경

- 적용 범위: 통합 mission planner의 허들 접근.
- 0.70m < Depth Z <= 1.0m: 현재 라인 중심점 연장선과 허들 박스 하단의 교차점을 사용.
- 로봇 보정 중심에서 좌우 오차가 영상 반폭의 10%를 넘으면 기존 line_recovery_left_4/right_4 모션을 실행.
- 교차점 유실 또는 허들 폭 밖 교차점이면 WAIT. 회전 전 교차점을 보관해서 재사용하지 않음.
- Depth Z <= 0.70m 또는 HURDLE_POSITIONING 진입 뒤에는 회전 금지와 미세 접근을 유지. 깊이 반등으로 회전을 재개하지 않음.
- Depth Z <= 0.54m의 기존 최종 GO 묶음 유지. 근접 중심각 70도 조건은 통합 경로에서 사용하지 않음.
- 허들 회전 배너는 HURDLE / LINE RETURN LEFT 또는 RIGHT 4.
- 공 제어 코드는 이번 작업에서 변경하지 않음.

검증: 직접 관련 검사 1334개 통과. 확장 검사 포함 1827개 통과, 21개 실패.
확장 실패 21개는 수정 전 별도 baseline 코드에서도 동일하게 발생했으며 새로운 실패 ID 없음.
기존 허들 우선순위 테스트 4개는 미세 접근 확인용 입력을 0.35m에서 0.60m로 수정했고,
다음 허들 상태 초기화 테스트도 새 교차점 회전 정책에 맞춰 갱신했다.
step/mission_control 빌드 완료. 설치본에서 좌회전, 700mm 미세 진입, 거리 반등 시 미세 유지 확인.
로봇 하드웨어 및 실제 물리 시뮬레이터는 실행하지 않았음.
복귀 모션에는 전진 성분이 있으므로 700mm 경계 통과 중 이미 시작한 모션은 완료까지 진행됨.
실기 전에 시뮬레이션에서 좌우 이동량과 경계 통과를 확인해야 함.
